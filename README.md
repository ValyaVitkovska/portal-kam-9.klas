# Портал към 9. клас — Математическа Експедиция

Интерактивна игра за преговор по математика след 8. клас. Седем царства покриват квадратни уравнения и формулите на Виет, рационални изрази и дробни уравнения, квадратни корени, вектори, средни отсечки и забележителни точки в триъгълника, окръжност с вписани и описани четириъгълници, и комбинаторика. Всяко преминаване съдържа 10 задачи с педагогическа прогресия — 3 основни, 5 средни и 2 с повишена трудност. Типовете задачи се избират наново при всяко влизане, така че играта не се изчерпва след първия път.

Освен задачите има интерактивна лаборатория с динамични построения, битка с Пазителя и стъпка по стъпка насоки при грешен отговор.

## Как се отваря

Отворете `index.html` в браузър — това е всичко. Не е нужна инсталация, сървър или интернет: всички библиотеки, шрифтове и изображения са в папката `assets/`.

## Публикуване в GitHub Pages

Качете съдържанието на тази папка в хранилище и включете Pages от **Settings → Pages**, с източник клона `main` и папка `/ (root)`. Ако качите цялата папка `portal-9-klas` в съществуващо хранилище, адресът ще бъде `https://<потребител>.github.io/<хранилище>/portal-9-klas/`.

Файлът `.nojekyll` е нужен, за да не пропуска GitHub Pages файлове при обработка — не го изтривайте.

## Структура

```
index.html                  цялата игра — разметка, стилове и логика
assets/css/                 tailwind.css, katex.min.css, fontawesome.min.css, fonts.css
assets/js/                  katex.min.js, auto-render.min.js
assets/fonts/               Inter, Playfair Display и шрифтовете на KaTeX (woff2)
assets/webfonts/            иконите на Font Awesome (woff2)
assets/img/                 logo.png, geo.png, avatar.svg, boss.svg
```

Всички пътища са относителни, затова папката работи еднакво локално, от USB и от GitHub Pages.

| Playfair Display | — | SIL OFL 1.1 |

`assets/css/tailwind.css` е компилиран само с класовете, които `index.html` използва. Ако добавите нови Tailwind класове в разметката, компилирайте го наново:

```
npm install tailwindcss@3
npx tailwindcss -i вход.css -o assets/css/tailwind.css --content index.html --minify
```

където `вход.css` съдържа трите реда `@tailwind base; @tailwind components; @tailwind utilities;`.

## Съвместимост

Проверена на ширини 360, 390, 834 и 1440 пиксела — телефон, таблет и лаптоп. Полето за пресмятания се показва свито на екрани под 640 пиксела, за да остане бутонът за проверка видим; отваря се с едно докосване. Работи с мишка, пръст и писалка.
